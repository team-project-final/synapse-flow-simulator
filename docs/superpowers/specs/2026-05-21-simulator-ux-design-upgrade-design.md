# Synapse Flow Simulator — 기능 + UI/UX + 디자인 개선 설계

**작성일:** 2026-05-21
**상태:** 승인 대기
**범위:** 시뮬레이터 기능 확장, UI/UX 개선, 디자인 폴리시

## 배경

Synapse Flow Simulator는 25개 시나리오, 52개 액터, 13가지 스텝 타입을 지원하는 인터랙티브 시스템 플로우 시각화 도구다. 현재 아키텍처 뷰와 시퀀스 뷰를 제공하며, Blueprint 다크 테마와 접근성(WCAG AA)을 갖추고 있다.

### 해결할 문제

1. **시나리오 탐색이 어려움** — 25개 시나리오가 카테고리별로 나열되어 있으나 검색/필터가 없음
2. **아키텍처 뷰 가독성** — 복잡한 시나리오에서 액터와 화살표가 뒤엉김
3. **사용 목적이 혼재** — 온보딩, 외부 발표, 개발 레퍼런스를 하나의 화면에서 모두 처리
4. **사용자 경험 흐름이 기술 흐름에 묻힘** — screen 액터와 ui_action 스텝이 아키텍처/시퀀스 뷰에 혼재

### 대상 사용자

- 팀 내부 온보딩 (학습)
- 교수/심사위원/외부 이해관계자 시연 (프레젠테이션)
- 개발 중 플로우 참조 (레퍼런스)

### 접근 방식

**레이어드 접근** — 모드 시스템과 3뷰 구조를 설계 단계에서 함께 잡되, 구현은 단계적으로 진행한다.

구현 순서:
1. 검색/필터 + 시나리오 네비게이션
2. UX 뷰 추가
3. 모드 시스템
4. 아키텍처 뷰 가독성 개선
5. 디자인 폴리시

## 섹션 1: 검색/필터 + 시나리오 네비게이션

### 1-1. 검색바

사이드바 최상단에 실시간 필터링 검색바를 추가한다.

- **검색 대상:** 시나리오 제목, 설명, 태그 (JWT, OAuth, Kafka 등)
- **한글/영문 모두 지원**, 입력 즉시 목록 필터링 (debounce 150ms)
- 결과 없을 시 "검색 결과 없음" 메시지 + 필터 초기화 버튼 표시
- `Ctrl+K` / `Cmd+K` 단축키로 검색바 포커스

### 1-2. 태그 필터 칩

검색바 아래에 수평 스크롤 가능한 필터 칩 영역을 추가한다.

- **카테고리 필터:** 인증, AI/이벤트, 장애, 운영, 학습자 여정, 관리자 여정, 보충 흐름
- **상태 필터:** implemented / partial / pending
- **우선순위 필터:** P0 / P1 / P2
- 복수 선택 가능, 토글 방식
- 활성 필터 수를 칩 옆에 뱃지로 표시

### 1-3. 시나리오 카드 정보 보강

현재 제목만 표시하는 시나리오 항목에 메타 정보를 추가한다.

- 태그 뱃지를 소형으로 표시 (예: `JWT` `bcrypt`)
- 스텝 수 표시 (예: "12 steps")
- 상태 도트 유지, hover 시 툴팁으로 상태 텍스트 표시
- 예상 소요 시간 표시 (ui.estimatedDuration 값 활용)

### 1-4. 최근 본 시나리오

사이드바 상단에 "최근" 섹션을 추가한다. 사이드바 순서: 검색바 → 필터 칩 → 최근 본 시나리오 → 카테고리별 시나리오 목록.

- 최대 3개까지 표시
- sessionStorage에 저장 (세션 간 유지 불필요)
- 빈 상태에서는 섹션 자체를 숨김

## 섹션 2: UX 뷰 (사용자 경험 뷰)

### 2-1. 뷰 탭 확장

기존 2탭을 3탭으로 확장한다.

- `아키텍처 뷰` | `시퀀스 뷰` | `사용자 경험 뷰`
- 아키텍처/시퀀스 뷰에서는 screen 액터와 ui_action 스텝을 **제외**하여 기술 플로우만 표시
- 사용자 경험 뷰에서는 screen 액터와 ui_action 스텝을 **중심에** 두되, 연관 API 호출을 보조로 표시

### 2-2. 화면 플로우 카드 레이아웃

UX 뷰의 메인 시각화는 가로 스크롤 카드 플로우로 구성한다.

각 스크린 카드 구성:
- **상단:** 스크린 이름 + kind 아이콘 (예: `로그인 화면`, `노트 에디터`)
- **중앙:** 해당 화면에서 일어나는 UI 액션 목록 (체크리스트 형태)
- **하단:** 이 화면에서 트리거되는 API 호출 요약 (소형 뱃지, 예: `POST /auth/login`)

카드 간 연결:
- 화살표로 화면 전환 흐름 표시
- 현재 스텝이 속한 카드가 하이라이트 (glowPulse 효과)

### 2-3. 스텝 재생 연동

기존 Play/Pause/Step 컨트롤이 UX 뷰에서도 동작한다.

- 현재 스텝이 ui_action이면 해당 카드 내 액션 항목이 강조 (배경색 변경)
- 현재 스텝이 API 호출이면 해당 카드 하단 뱃지가 pulse 애니메이션, 어떤 화면에서 촉발된 호출인지 시각적으로 연결 (점선)
- 자동 스크롤: 재생 시 현재 활성 카드가 뷰포트 중앙에 오도록 스크롤

### 2-4. 여정 시나리오가 아닌 경우의 처리

screen 액터가 없는 시나리오(인증, 장애, 운영 등)에서 UX 뷰를 선택할 경우:

- "이 시나리오에는 사용자 경험 흐름이 정의되어 있지 않습니다" 안내 메시지 표시
- 관련 여정 시나리오로의 링크를 제안 (예: "학습자 여정 P1을 확인해보세요")
- 빈 상태 전용 일러스트 표시

## 섹션 3: 모드 시스템 (학습 / 프레젠테이션 / 레퍼런스)

### 3-1. 모드 전환 UI

헤더 우측에 세그먼트 컨트롤을 추가한다.

- 3개 모드: `📖 학습` | `🎬 프레젠테이션` | `🔍 레퍼런스`
- 기본값: 학습 모드
- 선택한 모드는 sessionStorage에 기억
- URL 해시 파라미터로도 설정 가능 (예: `#mode=presentation`)

### 3-2. 학습 모드

현재와 유사한 3패널 레이아웃에 가이드 콘텐츠를 추가한다.

**레이아웃:** 사이드바(220px) + 메인 뷰 + 디테일 패널(280px) + 로그 패널(140px)

**정보 밀도 — 최대:**
- 디테일 패널에 **가이드 텍스트** 추가: 각 스텝이 왜 필요한지, 이 단계에서 알아야 할 개념 설명
  - 데이터 소스: scenarios.json의 기존 `annotations` 배열을 활용하되, 학습 모드에서는 annotations를 강조 스타일로 렌더링 (배경색 + 좌측 보더)
  - 추가로 scenarios.json의 각 스텝에 선택적 `guide` 문자열 필드를 추가하여 학습 전용 설명을 제공 (없으면 annotations만 표시)
- 브랜치(실패/대안) 섹션 기본 **펼침**
- 로그 패널 표시

**추가 기능:**
- 스텝별 "더 알아보기" 링크 (rules 필드의 §6.1 등 스펙 섹션 참조)

### 3-3. 프레젠테이션 모드

메인 뷰를 풀스크린으로 확장하고 부가 요소를 최소화한다.

**레이아웃:**
- 사이드바: 완전 숨김
- 시나리오 전환: 키보드 숏컷(↑↓) 또는 미니 드롭다운 (헤더 내)
- 디테일 패널: 하단 오버레이 바로 축소 (현재 스텝 한 줄 요약만 표시)
- 로그 패널: 숨김

**정보 밀도 — 최소, 시각적 임팩트 최대:**
- 액터/화살표 애니메이션을 더 부드럽고 눈에 띄게 (duration 증가, easing 개선)
- 시나리오 제목을 메인 뷰 상단에 크게 표시 (Space Grotesk 24px)
- 자동 재생 기본 활성화, 속도 1x

**추가 기능:**
- 키보드 `F` 키로 브라우저 전체화면(Fullscreen API) 토글

### 3-4. 레퍼런스 모드

검색과 기술 상세를 중심으로 한 레이아웃을 제공한다.

**레이아웃:**
- 사이드바: 너비 확장 (300px), 검색/필터 강조
- 디테일 패널: 메인 뷰 우측에 고정, 기술 상세 전부 표시
- 로그 패널: 표시

**정보 밀도 — 기술 상세 최대:**
- 페이로드 JSON 기본 펼침
- Kafka 토픽 정보 표시 (프로듀서, 컨슈머, 스키마 호환성)
- 관련 파일 경로(files 필드) 표시
- 스텝 타입별 필터링 가능 (http만, kafka만, db만 등)

**추가 기능:**
- 스텝 클릭 시 상세 정보 딥링크 (URL 해시로 공유 가능, 예: `#scenario=auth-login&step=3`)

## 섹션 4: 아키텍처 뷰 가독성 개선

### 4-1. 액터 그룹핑

같은 도메인의 서비스를 시각적으로 묶는다.

- 점선 박스로 그룹 표시 (예: Platform 서비스 + PostgreSQL + Redis = "Platform 그룹")
- 그룹 라벨을 박스 상단에 표시
- 그룹 간 충분한 간격으로 시각적 분리
- 시나리오에 참여하지 않는 액터는 표시하지 않음

그룹핑 기준은 scenarios.json의 액터 관계에서 도출한다:
- 같은 시나리오에서 직접 통신하는 서비스 + 데이터스토어를 같은 그룹으로 묶음
- 예: Knowledge 서비스 ↔ pgvector ↔ Elasticsearch = "Knowledge 그룹"

### 4-2. 화살표 가독성

화살표의 시각적 구분을 강화한다.

- 현재 스텝 화살표: **굵고 불투명** (stroke-width: 3, opacity: 1)
- 이전 스텝 화살표: **얇고 반투명** (stroke-width: 1.5, opacity: 0.3) — 잔상으로 흐름 맥락 유지
- 화살표 위에 액션 라벨 상시 표시 (예: `POST /login`) — 현재 마우스오버 필요한 것을 개선
- 동일 경로 화살표가 겹칠 때 자동 곡률 오프셋으로 분리
- 에러 스텝 시 경로가 붉은 점선 + shake 효과 (기존 유지)

### 4-3. 줌 & 팬

SVG 뷰포트 조작을 추가한다.

- 마우스 휠: 줌 인/아웃 (SVG viewBox 조절, 0.5x ~ 3x 범위)
- 마우스 드래그: 팬 (뷰 이동)
- 줌 리셋 버튼: "Fit to screen" (우측 하단 플로팅)
- `+` / `-` 버튼으로도 줌 조절 가능

### 4-4. 미니맵

줌 상태에서 전체 뷰의 위치를 파악할 수 있는 미니맵을 추가한다.

- 우측 하단에 소형 미니맵 표시 (120x80px)
- 현재 뷰포트 영역을 반투명 박스로 표시
- 미니맵 클릭으로 해당 위치로 이동
- 자동 숨김 조건: 프레젠테이션 모드, 또는 시나리오 액터가 8개 이하

### 4-5. 시퀀스 뷰 동일 적용

아키텍처 뷰의 가독성 개선을 시퀀스 뷰에도 적용한다.

- 줌 & 팬 동일 적용 (스텝이 15개 이상인 시나리오에서 세로 스크롤 문제 해결)
- 현재 스텝으로 자동 스크롤 (재생 시 뷰포트 중앙 유지)
- 이전 스텝 메시지 반투명 처리 (현재 스텝 강조)

## 섹션 5: 디자인 폴리시

### 5-1. 모션 & 트랜지션

뷰 전환과 상태 변경에 부드러운 애니메이션을 추가한다.

- **뷰 전환:** 크로스페이드 (opacity 0→1, 200ms ease-out)
- **모드 전환:** 레이아웃 리사이즈 애니메이션 (width/height transition 300ms)
- **시나리오 선택:** 메인 뷰 콘텐츠 페이드인 (150ms)
- **스텝 진행:** 활성 액터 카드에 미세한 pulse 효과, 비활성 카드는 부드럽게 dim
- **prefers-reduced-motion 존중:** 모든 애니메이션을 즉시 전환(duration: 0)으로 대체

### 5-2. 마이크로인터랙션

세밀한 인터랙션 피드백을 추가한다.

- 사이드바 시나리오 hover 시 미리보기 툴팁 (설명 + 태그 + 스텝 수)
- 재생 버튼 아이콘 morphing (▶ ↔ ⏸, SVG path 트랜지션)
- 속도 변경 시 숫자 카운트 애니메이션
- 검색 입력 시 매치 글자 하이라이트 (`<mark>` 태그)
- 브랜치 토글 시 접힘/펼침 슬라이드 애니메이션 (max-height transition)

### 5-3. 비주얼 업그레이드

시각적 완성도를 높인다.

- **액터 카드:** 단순 텍스트 박스 → kind별 아이콘 + 미묘한 그래디언트 배경
  - client: 모니터 아이콘, service: 서버 아이콘, datastore: DB 아이콘 등
  - 그래디언트는 kind 색상 기반 (5% opacity 정도의 미묘한 수준)
- **화살표 패턴 다양화:** HTTP(실선), Kafka(파형/물결), DB(점선), 에러(지그재그)
- **로그 패널:** 단순 텍스트 → 타임라인 형태, 스텝 타입별 아이콘 추가
- **빈 상태(empty state):** 시나리오 미선택 시, 검색 결과 없을 시 설명적 일러스트 + 안내 텍스트

### 5-4. 반응형 개선

태블릿 레이아웃을 추가하고 모바일 경험을 개선한다.

- **태블릿(900px~1200px):** 사이드바 축소(180px) + 디테일 패널 축소(240px), 메인 뷰 확보
- **모바일 UX 뷰:** 가로 스크롤 카드 → 세로 스택 (화면 너비에 맞춤)
- **터치 제스처:**
  - 스와이프 좌/우: 스텝 이동 (이전/다음)
  - 핀치 줌: 아키텍처/시퀀스 뷰에서 줌 인/아웃
  - 더블탭: 줌 리셋

## 기술 제약 사항

- **프레임워크 없음:** 순수 HTML/CSS/JavaScript 유지 (빌드 도구 없음)
- **단일 파일:** index.html 단일 파일 SPA 구조 유지
- **데이터:** scenarios.json 구조 확장은 하위 호환 유지 (기존 필드 제거 없음)
- **접근성:** WCAG AA 준수 유지, 새 컴포넌트에도 ARIA 속성 적용
- **성능:** 초기 로드 시간 증가 최소화, SVG 렌더링 최적화 필요
